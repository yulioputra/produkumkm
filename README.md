# Kuliner Desa Pegandon

## File utama
- `index.html` — struktur halaman
- `style.css` — tampilan desktop dan perangkat seluler
- `script.js` — interaksi dan fitur website
- `CNAME` — domain website
- `images/` — letakkan folder foto produk milik Anda di sini (sejajar dengan index.html)

## Pembaruan animasi dan pencarian
- Banner utama berganti otomatis setiap 4 detik dengan transisi crossfade.
- Menu Favorit berjalan terus satu arah dengan animasi transform yang halus, dapat dijeda saat kursor berada di atasnya, dan dapat digeser dengan mouse atau sentuhan.
- Kolom pencarian menyediakan pilihan `Nama Produk` atau `Kategori`.
- Filter kategori yang tersedia tetap dapat digunakan bersama pencarian.

## Menjalankan
Buka `index.html` melalui browser atau unggah seluruh isi folder ke hosting. Pastikan folder `images` dan nama file gambarnya tetap sama dengan yang dirujuk di HTML.

Catatan: fitur akun/admin pada versi front-end ini merupakan demonstrasi browser. Untuk penggunaan produksi, autentikasi dan data transaksi perlu dipindahkan ke backend yang aman.
